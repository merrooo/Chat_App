STEP 6 — Fresh keystore for Chat

if (Test-Path "release.keystore") { Rename-Item release.keystore release.keystore.Chat.bak -Force }
keytool -genkey -v -keystore release.keystore -alias Chat-key -keyalg RSA -keysize 2048 -validity 10000 -storepass "ChatApp2026!" -keypass "ChatApp2026!" -dname "CN=Chat, O=Chat, C=EG"
keytool -list -keystore release.keystore -storepass "ChatApp2026!"


Expected output:

Alias name: Chat-key
Entry type: PrivateKeyEntry
